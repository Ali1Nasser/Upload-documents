# P7 catalog status: group fx-a (State & FX, layer-level)

| Component | Status | Notes |
|---|---|---|
| PathDraw | implemented | Draws any SVG `d` as a lit route (04 §6 "a path is a lit route"): the path box is fitted into the slot, a hollow conduit (ink3 rim, void core) appears with a source node on the anchor frame (RV1), then the token-colour stroke fills it over the anchor word (one to three morph beats, `arrive` curve) with a white specular core and two soft halo strokes (standard / hero; no filter, no WebGL). Default direction is rtl (a path written left to right is drawn right to left; closed shapes counter-clockwise); with `arrowhead` a filled glowing head rides the pen tip and the stroke is trimmed under it, otherwise the arrival lights an end node with one pulse ring. After the draw a comet with a fading tail travels the route. Standard / hero add seeded sparks at the pen tip (count = tier particle cap / 100). Copy-free, so no text-safe mask and no Arabic of its own. Demo = a NilePay payment route drawn under the Arabic label; no number is shown, so no data-contract ref. Baselines pending-critic. Snap PASS det 0 qa 0. Perf box s/frame at 3 slots: lite 0.061, standard 0.083, hero 0.081 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass (1 string, OCR exact). Distinct from LineTrace (data series) and PipeFlow-style flows: PathDraw is the generic stroke reveal. |
| ShatterToBlocks | implemented | A document shatters into chunks (04 §6 embeddings / RAG): the receipts table is cloned into 16 DOM blocks (real pixels, seeded cuts along column / row gaps so no Arabic word is split) that burst outward from the impact point on the anchor word (outBack, staggered), tilt in 2D, grow shadows with lift and carry cyan key-light rims on the lit edges (ADR-003 LK-F). No WebGL: identical at all tiers except particle-free rim / shadow quality, so no separate fallback is needed. Demo = the NilePay receipts table (EGP values come from the demo table, no invented figures). Critic round 1: approved-critic 7.5, no blocking; non-blocking for the next re-baseline: keep a faint rim at hold, drop the two empty top-left chunks, add a burst-frame baseline, larger hero spread. Snap PASS det 0 qa 0. Perf box s/frame: lite 0.101, standard 0.127, hero 0.127 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass (OCR min 0.947). |
| MorphTextToObject | implemented | The anchor word dissolves right to left into outline-sampled particles that settle on a lit glass object (04 §6 "text becomes a thing"; demo: the Arabic word for "data" becomes a database cylinder), with key-light rim, floor glow and levitation gap; `direction` reverse bursts the object back to particles. The real word stays whole-Arabic DOM text (KText, auto-fit, text-safe mask); the particles are one seeded canvas painted on the settled frame (remotion `random` only; the canvas never draws a readable word). The canvas font is loaded explicitly before sampling (a cold first frame had sampled fallback glyphs: one non-deterministic run of 4 under load, fixed). Standard / hero add glow and more particles (tier cap); no WebGL, no number shown, so no data-contract ref. Critic round 1 approved-critic 7.5/10, no blocking (non-blocking for the next re-baseline: fade the text plate shadow with the word, scale the object about 1.3x, add a continuous rim under the dots, add a ~40 % in-flight baseline). Snap PASS det 0 qa 0. Perf box s/frame at 3 slots: lite 0.078, standard 0.120, hero 0.122 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass. Distinct from ShatterToBlocks (document to blocks) and PathDraw (stroke reveal). |
| Pulse | implemented | Pulses a target layer (`to`) 1 to 4 times (04 §6 "each light pulses as the narrator names it"). One pulse per beat (morph upper bound, 500 ms; 2 per second, under WCAG 2.3.1), the first on the anchor frame (RV1). The target breathes (scale 1 to 1.05 about its own centre, capped by the room its copy has inside title-safe) while it is lit as an object: an outer light swell (transparent box, so the glow is drawn outside the outline only, never over copy), a rim with a specular key-light top edge (ADR-003 LK-F) and emissive rings in the chosen token colour that expand from the outline and fade (camera ease). Standard / hero add a trailing second ring, a floor pool under the target and seeded sparks (12 / 20 dots, kept within 52 px of the rim; remotion `random` only); hero adds a third ring and a wider swell. Lite = one ring + swell + rim. No WebGL at any tier, so no separate fallback; no copy of its own, so no text-safe mask and no Arabic. Demo = the NilePay success rate (66.67 %, `d:5.2:7`) pulsing twice on the anchor word. Baselines pending-critic; the a1 still is pre-beat (CR-016), so `reports/p7/snap/Pulse_beat.jpg` shows the beat (standard f38/41/44/47/53 and hero f44). Snap PASS det 0 qa 0. Perf box s/frame at 3 slots: lite 0.071, standard 0.092, hero 0.084 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass (demo label, OCR exact). Distinct from FixSettle / FailureGlitch (status beats with chips and brackets) and LegendOrbs (own orbs): Pulse is the generic attention beat on any other layer.

| Shake | implemented | The failure shake (04 §3.5 exit, §6 failure beats; the only hard, un-eased motion in the film). The target layer (`to`), or every other layer of the shot when `to` is absent, jumps to a new seeded offset on every film frame for one settle length (400 ms) with a linear decay from `amplitude_px` (<= 12 px by schema), mostly horizontal, alternating sides; the first jolt lands on the anchor frame at full amplitude (RV1) and offsets are clamped so copy stays inside title-safe (the post-layout check reads the shaken position). With a `to` target the layer's REST box stays behind as a crit hairline rim (key-lit top edge) with a decaying outer swell and (standard / hero) a floor pool, so a still taken mid-shake shows how far it was thrown (ADR-003 LK-F). One decaying flash per shake (WCAG 2.3.1). No copy of its own (no text-safe mask), no WebGL at any tier, remotion `random` only. Demo = the NilePay receipts table (6 receipts, T3 and T6 failed, `d:5.2:1`) thrown on the word that names the failure, with the crit-highlighted failed rows and the Arabic label `العملية فشلت` kept still. Baselines pending-critic (p50 = one frame into the jolt). Snap PASS det 0 qa 0. Perf box s/frame at 3 slots: lite 0.077, standard 0.094, hero 0.095 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass (OCR exact). Distinct from Pulse (breathing attention beat with emissive rings) and FailureGlitch (chip / bracket status beat): Shake is the generic hard displacement of any layer. |
