| PathDraw | implemented | Draws any SVG `d` as a lit route (04 §6 "a path is a lit route"): the path box is fitted into the slot, a hollow conduit (ink3 rim, void core) appears with a source node on the anchor frame (RV1), then the token-colour stroke fills it over the anchor word (one to three morph beats, `arrive` curve) with a white specular core and two soft halo strokes (standard / hero; no filter, no WebGL). Default direction is rtl (a path written left to right is drawn right to left; closed shapes counter-clockwise); with `arrowhead` a filled glowing head rides the pen tip and the stroke is trimmed under it, otherwise the arrival lights an end node with one pulse ring. After the draw a comet with a fading tail travels the route. Standard / hero add seeded sparks at the pen tip (count = tier particle cap / 100). Copy-free, so no text-safe mask and no Arabic of its own. Demo = a NilePay payment route drawn under the Arabic label; no number is shown, so no data-contract ref. Baselines pending-critic. Snap PASS det 0 qa 0. Perf box s/frame at 3 slots: lite 0.061, standard 0.083, hero 0.081 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass (1 string, OCR exact). Distinct from LineTrace (data series) and PipeFlow-style flows: PathDraw is the generic stroke reveal. |
| ShatterToBlocks | implemented | A document shatters into chunks (04 §6 embeddings / RAG): the receipts table is cloned into 16 DOM blocks (real pixels, seeded cuts along column / row gaps so no Arabic word is split) that burst outward from the impact point on the anchor word (outBack, staggered), tilt in 2D, grow shadows with lift and carry cyan key-light rims on the lit edges (ADR-003 LK-F). No WebGL: identical at all tiers except particle-free rim / shadow quality, so no separate fallback is needed. Demo = the NilePay receipts table (EGP values come from the demo table, no invented figures). Critic round 1: approved-critic 7.5, no blocking; non-blocking for the next re-baseline: keep a faint rim at hold, drop the two empty top-left chunks, add a burst-frame baseline, larger hero spread. Snap PASS det 0 qa 0. Perf box s/frame: lite 0.101, standard 0.127, hero 0.127 (budgets 0.201 / 0.201 / 1.038). Arabic QA pass (OCR min 0.947). |
| MorphTextToObject | implemented | The anchor word dissolves right to left into outline-sampled particles that settle on a lit glass object (04 §6 "text becomes a thing"; demo: the Arabic word for "data" becomes a database cylinder), with key-light rim, floor glow and levitation gap; `direction` reverse bursts the object back to particles. The real word stays whole-Arabic DOM text (KText, auto-fit, text-safe mask); the particles are one seeded canvas painted on the settled frame (remotion `random` only; the canvas never draws a readable word). The canvas font is loaded explicitly before sampling (a cold first frame had sampled fallback glyphs: one non-deterministic run of 4 under load, fixed). Standard / hero add glow and more particles (tier cap); no WebGL, no number shown, so no data-contract ref. Critic round 1 approved-critic 7.5/10, no blocking (non-blocking for the next re-baseline: fade the text plate shadow with the word, scale the object about 1.3x, add a continuous rim under the dots, add a ~40 % in-flight baseline).
